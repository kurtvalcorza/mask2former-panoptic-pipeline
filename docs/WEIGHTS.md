# Weight provenance and DIMER hosting

- Upstream: `facebook/mask2former-swin-tiny-coco-panoptic`
- Immutable revision: `df6b1142ff50c3276559d9d78f35f6a579c75a77` (the Hub's `main` resolved to this commit on 2026-09-18; repository created 2023-01-02, last modified 2023-09-11)
- Weight format: SafeTensors (`model.safetensors`, 190,052,872 bytes, float32). The upstream repository also hosts `pytorch_model.bin` (190,172,069 bytes), a pickle checkpoint that DIMER does not accept and this pipeline neither lists nor loads.
- Manifest: `weights/mask2former-swin-tiny-coco-panoptic/dimer-base-manifest.json` (4 files: `README.md`, `config.json`, `model.safetensors`, `preprocessor_config.json`; 190,138,785 bytes total, per-file SHA-256)
- Upstream weight license: **MIT, resolved rather than declared.** The Hub checkpoint carries a `license: other` tag and its card names no licence text. The upstream code repository `facebookresearch/Mask2Former` is MIT (`LICENSE`, Copyright (c) 2022 Meta, Inc.); its README states that the majority of the project is MIT with the vendored Swin-Transformer-Semantic-Segmentation code under MIT and Deformable-DETR under Apache-2.0, and makes no separate statement about the released weights — it neither excludes them (as the CLIPSeg repository does) nor names another licence. The DIMER fleet matrix resolved the weights to MIT on that basis on 2026-09-14 (row released from HOLD), and `MODEL_CARD.md` records `license: mit` with this note. A deployment that needs certainty should confirm the weight licence with the upstream authors. The COCO annotations the model was trained on are CC BY 4.0; the COCO images carry individual Flickr licences.
- DIMER hosting: MIT permits use, modification, distribution, and commercial use subject to preservation of the copyright and licence notice. The Git repository does not vendor the checkpoint (`weights/**/*.safetensors` is git-ignored); DIMER may mirror the pinned snapshot in its model store under the upstream licence with the notice preserved.
- Adapted artifacts: `save_artifact` writes a full re-headed copy of the model (`model.safetensors` of the same size, `config.json` with the new vocabulary, `preprocessor_config.json`, `dimer-adapted-manifest.json`); it is a derivative of the upstream weights and carries the same licence obligations. The tutorial's artifact is produced in the notebook runtime and is not committed or hosted by this repository.
- Fresh clone: `stage_missing_files(allow_download=True)` fetches only the manifest-listed files absent on disk, at the pinned revision, into the snapshot directory; `verify_snapshot()` then checks every file before any load. `weights/**` is marked `-text` in `.gitattributes` so Windows `core.autocrlf` cannot rewrite the committed small files and break their digests.
- Loader trust boundary: Transformers `Mask2FormerForUniversalSegmentation` / `AutoImageProcessor` (the slow `Mask2FormerImageProcessor` the snapshot declares: 384×384 resize with ImageNet mean/std, `ignore_index` 255) with `trust_remote_code=False`, `local_files_only=True` from the verified directory; nothing is fetched at construction, inference or training (the smoke run loaded, segmented and fine-tuned with `HF_HUB_OFFLINE=1`). The pinned processor configuration carries a `_max_size` key the pinned `transformers` reports as not valid for the class (a warning at load; the value is ignored).
